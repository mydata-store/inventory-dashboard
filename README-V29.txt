Inventory Common Framework V29 — Complete Theme Controller

This version rebuilds the Theme Controller as a full visual design package.

Included:
- Page width, maximum width, minimum height, padding and layout mode.
- Workspace, page, card, border, radius, padding and shadow design.
- Top bar, titles, subtitles, header height, alignment and freeze/unfreeze.
- Complete table designer: header, rows, borders, density, zebra rows,
  frozen header and frozen-column setting.
- Complete button designer: size, radius, border, icon position, hover,
  shadow and color schemes.
- Graph designer: bar, line, area, pie, doughnut and gauge defaults,
  graph colors, size, legends, labels, tooltips, animation, grid and export.
- Font Manager inside Theme Controller with independent fonts for:
  main page, sidebar, top bar, titles, subtitles, section headers,
  table headers, table body, form labels, inputs, buttons, graph titles
  and graph labels.
- Advanced live preview.
- Save scope options for entire ERP, current page and selected pages.
- Global CSS design tokens so future ERP pages can inherit settings.

Install:
1. Replace erp-design-studio.html
2. Replace public/common-theme-manager.js
3. Replace public/common.css
4. Run erp-theme-controller-v29.sql once (safe to run again)
5. Refresh with Ctrl+Shift+R
