Print Design Studio

Build reusable print designs, start from Print Page Themes, save finished designs in Print Gallery, and assign them to ERP pages through a standard Print Data Contract.

Print Data Contract: every printable ERP page will register its page ID, available fields, rows, totals and optional header information. Print Design Studio reads that contract, so the print design stays independent from the page's HTML layout.
