Registered Page Access

Every future ERP page can register itself here. Give access to only the exact pages this role is allowed to open.

Automatic Access Contract: when a new page such as Boiler Fuel, Steam Cost or Steam Consumption is created, it registers its Page ID and immediately becomes available in this table. No User Management redesign is required.
Future pages: when we create a new ERP page, its connector registers the Page ID here. You then select the role and tick only the actions that role may use. Direct page opening can be blocked with the same permission contract.
