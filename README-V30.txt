ERP Design Studio V30 — Controller Navigation Foundation

This update changes only ERP Design Studio navigation.
The completed Universal Sidebar remains locked and unchanged.

Included:
- Entire controller cards are clickable.
- Keyboard support: Enter or Space opens a controller.
- Only one controller panel remains open.
- Selected controller is highlighted in both the left controller list and Control Center.
- Breadcrumb shows the current workspace.
- Clicking Control Center returns to the main controller cards.
- Every page refresh starts at Control Center.
- Opening a controller scrolls the workspace to the top.
- Smooth panel transition added.

Install:
1. Replace erp-design-studio.html
2. Refresh with Ctrl+Shift+R

No SQL is required.
No sidebar files are changed.
