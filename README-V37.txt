ERP Design Studio V37 — Profile Controller

Profile Controller features:
- Profile selector with New, Duplicate, Delete and Set Active.
- Profile templates: Store Keeper, Purchase Officer, Store Manager,
  Workshop Manager, Accounts, Administrator and Read Only.
- General Information.
- Profile Card Designer with live preview.
- Picture Manager with upload, URL, zoom, rotate, frames and removal.
- Display Options.
- Dashboard Assignment.
- Grouped Permissions.
- Notification Center.
- Login & Security.
- Digital Signature and Stamp.
- Theme Assignment.
- Activity Log.
- Full-screen profile preview.
- Multiple profiles saved in browser localStorage.

Install:
1. Replace erp-design-studio.html
2. Refresh using Ctrl+Shift+R

No SQL is required.
No locked sidebar files were changed.
