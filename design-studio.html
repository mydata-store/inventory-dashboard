How to Use Report Studio

Create once, save as a template, and run the report whenever required.

1. SetupName the report and select its module.
2. BuildUse Toolbox and Columns to choose what appears.
3. FilterSelect date, supplier, item and other runtime filters.
4. DesignChoose theme, paper, borders, footer and signatures.
5. SaveSave the design as a reusable template.
6. RunClick Run Report to open the full report preview, then export or print.
Example: Create “Daily Local Purchase”, select Date + Item + Size + Qty + Unit + Rate + Amount + Remarks, save it, and reopen it every day with a new date.
