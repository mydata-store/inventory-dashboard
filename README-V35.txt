ERP Design Studio V35 — Two-Panel Property Editor

Locked work remains unchanged:
- Universal Sidebar
- Full-width ERP Design Studio
- Horizontal controller navigation
- Theme Controller foundation
- Page Builder foundation

Page Builder upgrades:
- Fields Designer now uses a left object list and right property editor.
- Only one field is edited at a time.
- Fields remain draggable for reordering.
- Field properties are grouped into General, Validation, Autofill,
  Appearance and Advanced tabs.
- Table Designer uses the same left-list / right-properties architecture.
- Buttons Designer uses the same architecture.
- Duplicate and Delete actions are available for selected objects.
- Search boxes are available for Fields, Columns and Buttons.
- Live previews are available for selected fields, columns and buttons.
- This layout avoids long scrolling and scales to large ERP pages.

Install:
1. Replace erp-design-studio.html
2. Refresh using Ctrl+Shift+R

No SQL is required.
No sidebar files were changed.
