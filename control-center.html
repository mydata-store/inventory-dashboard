Theme Studio

Choose a complete ERP theme. Every preset controls the workspace, sidebar, top bar, profile card, cards, forms, tables and buttons.

Color Studio

Fine-tune every important surface instead of changing only the sidebar.

Sidebar Design Studio

Design the Universal Sidebar precisely. Main menus, submenus, branding, spacing and animation can be controlled separately.

Profile Card Designer

Build the single profile card completely: picture, crop, frame, shape, typography, status and card geometry.

Photo Preview

The selected picture is stored in Control Center settings and applied to the single sidebar profile card.

Typography & Spacing

Control fonts, sizes, density, box spacing and component geometry throughout the ERP.

Component Studio

One setting updates cards, inputs and buttons across all connected pages.

Table Studio

Control table readability and visual hierarchy for master, entry and report pages.

Page Controller

Apply special overrides to individual pages while they still inherit the global theme.
